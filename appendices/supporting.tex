\section{Field and open-source inspiration}
The \emph{Joint Interdisciplinary Field Trip---Technology, Computation, Culture \& Society in Action} took place on September 4, 2026, at \textbf{Tencent Shanghai Office} and \textbf{Shanghai Science and Technology Museum}. I attended both sites.

At Tencent, I directly observed a physical separation between GPU-heterogeneous and CPU general-purpose servers, plus an on-site renewable-energy display; I infer that any AI-assisted verification feature carries a real compute and energy cost that a Static Space cannot remove -- it only avoids a dedicated GPU runtime, not the underlying resource question. This connects to Segment Anything (Meta AI, Apache-2.0), an open-source tool showing that a small, inspectable model is preferable to an opaque large-model API for a verification feature.

At the Shanghai Science and Technology Museum, I directly observed 1985--86 portable computers as bulky, screen-limited, and non-networked; I infer that today's AI-assisted verification is only possible because computing moved from isolated devices to interconnected platforms. This connects to Haztrak (U.S. EPA, MIT license), an open-source tool showing that auditable, licensed, publicly inspectable infrastructure is a proven governance path for tracking custody -- the model for the accountability log proposed in Section 5.
