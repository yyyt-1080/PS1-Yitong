# Appendix E structured abstract

## Student template

| Proposal element | Current statement or change |
| --- | --- |
| Background | State the strategic setting, established knowledge and unresolved issue. Cite the foundation. |
| Motivation and application | Explain why the issue matters now, the application and the people affected. |
| Three connected questions | Give the economics, computer-science and behavioral-science questions, followed by the integrated question. |
| Method and model assumptions | Specify players, strategies, incentives, timing and information; then the model, baseline and evidence needed. |
| Results or expected results | Separate actual findings from expected outcomes. State the evidence type and what could challenge the prediction. |
| Intellectual merits | Explain the advance beyond the foundation and the insight made possible by combining the three disciplines. |
| Practical impacts | Identify private- and public-sector value and the open-access tool’s intended SDG 4 learning contribution. |
| Feedback received and revision made | Name the dated feedback, earlier claim, actual change and consequence. Retain prior versions; state if feedback is pending. |

## Worked class example

| Proposal element | Current statement or change |
| --- | --- |
| Background | Language models make decisions whose outcomes depend on other agents. Equilibrium matching alone does not explain strategic reasoning. |
| Motivation and application | Negotiation, competition and coordination require models that anticipate others. The proposal studies controlled complete- and incomplete-information games. |
| Three connected questions | Economics: depth or response noise? Computation: how should recursive strategic capability be evaluated? Behavior: how do human-like limits and demographic framing affect choice? Together: how do these factors jointly explain LLM strategic behavior? |
| Method and model assumptions | Reconstruct Jia et al.’s design prospectively: 22 LLMs, 13 game settings, 30 baseline trials per model and game; TQRE estimates depth and precision. Compare prompts, available explanations, token use, personas and published human evidence. |
| Results or expected results | Hypotheses: depth differs across games, longer reasoning need not improve choices, and persona cues may shift behavior. No 22-model experiment was run for this teaching proposal; the optional code pilot is synthetic. |
| Intellectual merits | Integrate Rogers et al.’s quantal response, Zhang et al.’s recursive LLM reasoning, Camerer et al.’s human reasoning levels and Gupta et al.’s persona audit within one evaluation. |
| Practical impacts | Inform agent selection and contextual audits, subject to validation. An open-access learning game can explain depth versus noise for SDG 4; learning benefits remain to be assessed. |
| Feedback received and revision made | September 9, 2026 instructor direction: use the in-class Jia et al. reconstruction. The sample now centers the 22-model study and keeps the small synthetic pilot explicitly separate. No student workshop feedback is invented. |
